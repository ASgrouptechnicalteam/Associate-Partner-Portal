# Application Architecture

## Data Flow
React PWA
↓
Express REST API
↓
Prisma
↓
MySQL

## Core Components
1. **Frontend (Vite + React)**: Handles UI, state, and PWA capabilities. Communicates with the backend via REST endpoints.
2. **Backend (Express API)**: Processes requests, enforces RBAC logic, handles file uploads, and securely manages JWT sessions.
3. **Database (MySQL + Prisma)**: Persistent storage with strictly typed schemas generated by Prisma.

## Security
- Authentication tokens are issued as HTTPOnly cookies to prevent XSS.
- Passwords are one-way hashed using `bcrypt` (10 rounds).
- API inputs are rigidly validated using `zod`.
